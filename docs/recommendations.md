# 推荐推送

入口：发布模式 → 定时任务下方的「⭐ 推荐推送」。

1. 在发布模式选择并确认目标频道，进入推荐菜单，新建一期。
2. 先输入自定义文案，再输入特别推荐关键词。一行一个，也支持空格、逗号分隔；重复关键词自动去重。
3. 点击「继续普通发布」，直接输入资料关键词，或创建定时任务。
4. 更新完成后回到推荐菜单，预览各目标的消息，再确认推送。

推荐只收集本期开启后、完整成功的发布任务。手动发布、上传后发布、定时发布共用记录。未开启推荐时不记录推荐链接，也不自动发推荐消息。

每个目标使用该频道或超级群自己的消息链接；同一关键词有多组资料时分别显示「第1组」「第2组」。普通群不支持此功能。私有频道的访问者需要先加入频道。

## 追加和修改

- 「添加关键词」保留文案和已有关键词。若该关键词已经在本期发布过，直接关联已有记录；否则等待后续成功发布。
- 「修改文案」「移除关键词」仅修改草稿，需重新预览并确认更新频道消息。
- 已推送的推荐再次确认时编辑原消息，不新增推荐帖。
- 所选关键词尚未全部发布到每个目标时，预览会列出缺失项。可以发布缺失资料，或从推荐中移除对应关键词。
- 「结束本期」需要确认；之后停止收集，已有频道推荐帖保留。下一期需重新创建。
- 目标频道在创建本期时确定，之后普通发布选择其他频道不会改变本期推荐目标。

## 持久化与异常

草稿、资料链接和已推送消息编号保存于数据库所在目录的 `recommendations.json`，应随数据目录一起备份。

发送结果不确定时阻止自动重复发送。核对频道后，若推荐帖已经出现，管理员可私聊发送 `/recommend_bind 推荐消息链接`，绑定后重新预览更新。若频道中没有该消息，应先排查请求状态，由维护人员核实后处理，避免重复推送。编辑失败不会另发一条替代消息。

运行检查：`node scripts/recommendations-check.cjs`（先编译 TypeScript）。测试使用独立临时目录和模拟 Telegram 接口，不向真实频道发消息。
