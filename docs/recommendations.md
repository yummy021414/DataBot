# 特别推荐

入口：发布模式 → 定时任务下方「⭐ 推荐推送」。

## 推荐流程

1. 在发布模式选择并确认目标频道或超级群，打开推荐菜单，点击「让机器人先发文案」。把带格式、文字链接的文案发给机器人；机器人会立即代发到所选目标。
2. 点击「继续普通发布」，照常发布资料，也可使用定时任务。推荐关键词可以等发布完再选。普通发布不会自动改推荐文案。
3. 发布完成后，打开推荐菜单，输入特别推荐关键词。支持连写、空格、换行、逗号；以资料库关键词拆分。每个关键词对应一个按钮。
4. 预览按钮并确认。机器人只编辑第一步那条原文案的按钮，按钮跳转到对应目标里的资料消息，不再另发推荐帖。

也可先自行发送文案、照常发布，再选择「我已手动发文案」并提交文案消息链接；或私聊使用 `/recommend_bind https://t.me/c/频道编号/消息编号`。绑定后添加关键词并编辑按钮。Telegram 可能不允许机器人编辑由用户发出的原消息；若接口拒绝，机器人会明确报错，不会另发替代消息。机器人代发文案是稳定方式。

一个关键词多次发布时，链接取文案消息之后最近一次完整发布的第一组。只使用同一频道或超级群、同一管理员发布的资料（超级管理员可使用所有管理员资料）。未完整成功的发布任务不写入推荐记录。频道和超级群的私有消息链接要求访问者已经加入对应聊天。

## 管理与数据

同一期可继续普通发布并添加关键词，再次确认会更新原消息按钮。结束本期后，可开始新的文案和推荐。建议在全部资料发布完成后选关键词，确保按钮只指向本期实际发布的资料。

推荐草稿和文案消息编号保存在数据库目录的 `recommendations.json`。完整发布记录保存在同目录的 `recommendation-publications.json`，保留 90 天。两份文件都应随数据目录备份。发送文案的结果不确定时会阻止自动重发；核对目标后可使用 `/recommend_bind` 绑定已存在的消息。

运行检查：先编译 TypeScript，再运行 `node scripts/recommendations-check.cjs`。检查使用临时目录和模拟 Telegram 接口。
