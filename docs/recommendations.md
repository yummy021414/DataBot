# 特别推荐

入口：发布模式 →「⭐ 推荐推送」。

1. 正常发布资料。文案在资料之前或之后发到目标频道、超级群均可。
2. 在推荐菜单点击「提交文案消息链接」，把目标中原文案的 Telegram 消息链接发给机器人；也可私聊发送 `/recommend_bind 消息链接`。
3. 输入特别推荐的资料关键词。支持连写、空格、换行、逗号；会按资料库关键词拆分，一个关键词生成一个按钮。
4. 预览并确认，机器人从**今天（北京时间）已完整发布**到同一目标的资料中查找每个关键词，编辑原文案消息的按钮。文案正文保持不变，不新发消息。

若一个关键词今天发布多次，按钮指向最近一次完整发布的第一组。普通发布、上传后发布、定时发布共用完成记录；发布中途失败的任务不会纳入推荐。频道和超级群的私有消息链接要求访问者已加入相应聊天。

可继续添加或移除关键词，再次确认会更新同一条原文案消息的按钮。「结束本期」后可以绑定另一条文案消息。今日资料记录保存在数据库目录的 `recommendation-publications.json`，保留 90 天；草稿和绑定的消息编号保存在 `recommendations.json`。备份数据目录时应包含这两个文件。

Telegram 可能不允许机器人编辑用户自行发送的消息。若接口拒绝，机器人会返回具体错误，不会另发替代消息。要保证后续可编辑，原文案需要由机器人账号发送；本功能只负责绑定链接和编辑按钮。

运行检查：先编译 TypeScript，再运行 `node scripts/recommendations-check.cjs`。检查使用临时目录和模拟 Telegram 接口。
